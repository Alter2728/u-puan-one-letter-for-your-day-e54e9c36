An entry for make.fun's [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) bounty ($5 in USDC): a program that writes exactly one letter, A to Z, standing for the word that describes the day.

`main.py` (Python 3.13, standard library only) writes a single character to `/output/entry.txt` — no word, no gloss, no punctuation. The output is deterministic: every run writes the same letter, exactly 1 character as the gate requires.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
